There are a few things you might want to know before you try to use these config files:

I'm not sure if these work on every Linux distribution. So, I would recommend using Arch Linux, or an Arch-Based distribution like Artix, CachyOS, or EndeavourOS

Second, you're gonna want to install all the programs that I have a configuration file for in the .config directory. These should all be available via pacman, apt, dnf, etc with the exception of the zsh plugins that I use. Those aren't really necessary, but they look nice and offer some extra functionality. If you want to use those plugins, you'll want to install oh-my-zsh and starship.

I'll add an install script for all of these things soon, so this will become unnecessary.
