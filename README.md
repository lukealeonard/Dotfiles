# My dotfiles
There are a few prerequisites for using these dotfiles on your computer:

First, make sure you're using Arch Linux or an arch based distribution of linux, like CachyOS.
Second, you're gonna want to install all the programs that I have a config for in the .config folder. These should all be available via pacman, with the exception of oh-my-zsh along with the zsh plugins and starship.
Third, install oh-my-zsh and starship. I use the syntax and autosuggestions plugins with oh-my-zsh, but you can edit .zshrc and change any plugins you like.
The desktop and laptop dotfiles are a little different. I prefer a different look to my desktop computer, which has multiple monitors. The desktop version is available in the desktop branch.
